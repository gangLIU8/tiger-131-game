# 虎式 I 型 · 131 · 靶场

开着这台虎式在靶场里跑，把场上的 8 个靶子全部打掉。
纯 Three.js，单文件逻辑，无框架、无外部 CDN，双击 bat 就能玩。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 游戏全部内容（HUD / 场景 / 物理 / 逻辑） |
| `tiger.glb` | 带零件层级的坦克模型 + 1K 烘焙贴图，**1.2 MB** |
| `Tiger_game.blend` | 游戏版 Blender 源文件（炮塔可转、履带 104 片独立、20 个轮子独立） |
| `vendor/` | Three.js r169 + GLTFLoader |
| `本地预览.bat` | 双击起本地服务器并打开浏览器 |

## 本地预览

双击 `本地预览.bat`，会打开 `http://127.0.0.1:8778/`。

> 不要直接双击 `index.html`：浏览器对 `file://` 页面限制加载 `.glb` 和 ES 模块，必须走 http。

## 操作

| 键 | 作用 |
|---|---|
| `W` / `S` | 前进 / 倒车 |
| `A` / `D` | 左转 / 右转（原地就能转向） |
| 鼠标移动 | 炮塔和炮管跟随鼠标指的落点 |
| 左键 / `空格` | 开火（装填 2.4 秒） |
| 滚轮 | 镜头拉远拉近 |
| `R` | 重来 |
| `Esc` | 暂停 |

手机上：左下摇杆开车，右半屏拖动转炮塔，右下按钮开火。

## 玩法

- 8 个靶子：5 个固定，3 个沿铁轨来回移动。
- 炮弹 130 m/s、有重力下坠，打远处移动靶要算提前量。
- 全部击毁后显示用时，可以再来一次。

## 坦克是怎么动起来的

模型不是一整个网格，而是拆成了能各自转动的零件：

- `Turret_Pivot` 炮塔（绕 Y 轴，网页里限速 1.35 rad/s 跟随鼠标）
- `Gun` 炮管（原点在耳轴，绕 X 轴俯仰 −8°~+20°，带后坐）
- `Wheel_L/R_00..09` 20 个轮子（8 个负重轮 + 主动轮 + 诱导轮 / 每侧）
- `Track_L/R_00..51` 104 片履带板

履带板在网页里不是逐个播放动画，而是：读取 52 片履带板的初始位置 → 最近邻连成一条闭合折线 → 按弧长参数化 → 每帧按履带速度推移，位置沿折线插值、朝向取切线。
左右履带速度按差速算：`vL = v − ω·1.41`、`vR = v + ω·1.41`，所以原地转向时两条履带反向走。

### 两个必须记住的坑

1. **所有零件的旋转/缩放都烘进网格了**（`transform_apply(rotation=True, scale=True)`）。
   拆件时从合并网格里分出来的零件带着 −78° 的物体旋转，网页里直接写 `rotation.x` 会互相打架。
2. **导出前必须 `hide_view_clear`**。隐藏的物体会被 `use_selection` 静默漏掉，之前就漏过一片 `Track_L_35`。

## 发到 GitHub Pages

1. GitHub 新建 Public 仓库，把本目录内容上传到仓库根目录（`index.html` 要在根目录）
2. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`
3. 等 1~2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`
